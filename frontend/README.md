# Student Study Planner - React Native Frontend

Cross-platform mobile and web frontend for the Student Study Planner built with Expo SDK 51, Expo Router, TypeScript, and Firebase Auth.

## Setup Instructions

1. Install dependencies:
   ```bash
   npm install
   ```

2. Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```
   Fill in your Firebase web application configuration credentials.

3. Start the Expo development server:
   ```bash
   npx expo start
   ```

   - Press `w` to open web application in browser.
   - Press `a` to run on Android emulator or `i` for iOS simulator.
